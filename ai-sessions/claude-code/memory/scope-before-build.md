Before planning implementation details or writing code, agree with the user on **what** gets built (scope tiers), **in what order** (milestones), and **how it will be verified** (test cases). Don't jump from data exploration straight to an architecture plan + ExitPlanMode.

**Why:** On the candidate-search challenge (2026-09-19) the user rejected a full implementation plan: "before we even start… we need to decide scope, build order, test cases."

**How to apply:** Lead with a scoping doc (must/should/could/won't, milestone order with exit criteria, test matrix), get decisions via questions, then detail the implementation.
